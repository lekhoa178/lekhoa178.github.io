# Managed portfolio crawler policy

This repository serves https://lekhoa178.github.io/robots.txt for the portfolio at https://lekhoa178.github.io/online-portfolio/.

Only /online-portfolio/ is opted out of selected training and bulk-dataset crawlers. Search and user-directed retrieval remain allowed. Other project sites on this hostname are unaffected.

The portfolio's private authoring project generates these four files through scripts/deploy-crawler-policy.mjs. Keep changes there so future deployments preserve them. No portfolio source or assets belong in this repository.

robots.txt is a voluntary preference, not access control.
